# 🐉 Aksara Naga HSK

### Mandarin HSK Learning Academy

Aksara Naga HSK is a dedicated Mandarin learning application focused on the HSK curriculum.

The application provides a structured learning environment for studying Mandarin from HSK 1 to HSK 6.

## ✨ Features

- HSK 1–6 learning materials
- Mandarin vocabulary
- Grammar learning
- Interactive exercises
- Structured learning progression
- Learning progress support

## 📚 Curriculum

- HSK 1
- HSK 2
- HSK 3
- HSK 4
- HSK 5
- HSK 6

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the main HTML file in a modern browser.
3. Select an HSK level to begin learning.

## 🛠️ Technology

- HTML5
- CSS3
- JavaScript
